# Money Flow reference check

Checked: 2026-09-12. Scope: first-party product pages and App Store release notes. No app installation, gesture test, or performance test.

## Likely identity

The likely reference is **Money Flow by Hermann Wagenleitner**, App Store ID `900890647`. Its current US title is **Budget Planner - Money Flow**; the previous Spending Tracker URL redirects to that title. This is a likely match, not a confirmed identification from the user. [App Store](https://apps.apple.com/us/app/budget-planner-money-flow/id900890647)

The developer site advertises quick transaction entry, a simple interface, a calculator, reports, budgets, and device synchronization. These are product claims. The reviewed first-party text does not describe the specific microgestures that the user remembers. Speed and interaction quality still need direct inspection. [Product site](https://moneyflow.cloud/en)

## Import and synchronization

- **Some automatic capture is now advertised.** Version 1.44, shown as August 18 in the current 2026 release history, adds Apple Wallet automation through Shortcuts on iOS 17+. It also advertises voice entry, balance and budget queries, transaction search, and CSV export through Siri and Shortcuts. This has not been tested. [App Store release notes](https://apps.apple.com/us/app/budget-planner-money-flow/id900890647)
- **A bank feed is not established by those claims.** No direct bank-connection feature was found in the reviewed product page, support index, or listing. Wallet automation does not demonstrate retrieval of complete bank history or bank balances. Absence from these sources is not proof that a feature cannot exist. [Product site](https://moneyflow.cloud/en), [Support index](https://www.moneyflow.cloud/en/support), [App Store](https://apps.apple.com/us/app/budget-planner-money-flow/id900890647)
- **Device synchronization is distinct.** The documented method uses an email/password profile, independent of an Apple Account, including shared use with other people. [Synchronization help](https://www.moneyflow.cloud/support/article?p=help%2Fsync)
- **iCloud is documented for backups.** The migration guide separately describes backups, device synchronization, and CSV import/export. It says synchronization omits recurrence settings and images. CSV contains transactions and omits budgets, goals, account groups, images, and unused entities. [Moving data](https://www.moneyflow.cloud/en/support/move-data)

## Name ambiguity

Other products have similar names. **MoneyFlow - Expense Tracker**, by Jason Pan, has App Store ID `6470766304`. **Money Flow**, by Abstract Software LLC, uses `moneyflow.app` and explicitly promotes manual entry without bank linking. Do not combine their capabilities or privacy claims with Wagenleitner's app. [Jason Pan listing](https://apps.apple.com/ie/app/moneyflow-expense-tracker/id6470766304), [Abstract Software product](https://www.moneyflow.app/)

## Implication for discussion

Use the remembered interaction quality as the user's design reference. Treat the app identity as provisional. If this is the right app, the current distinction is between limited automated capture and a verified financial-institution feed, rather than between manual input and all automation.
